# Security and privacy

This project is a local, single-user demonstration and does not currently provide
authentication or authorization. Do not expose it to an untrusted network or use it
to process real student records without an independent security and privacy review.

To report a vulnerability, contact the repository owner privately through their
GitHub profile. Do not include student data, credentials, private source documents,
or exploit details in a public issue.

Only the latest repository state is supported. Security reports should identify the
commit tested, affected route or component, reproduction conditions, and potential
impact without attaching private data.
